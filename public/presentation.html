Architecture 5 / 10

How it works

Request to response

01

Patient sends a message

Chat request streams via Next.js API route using Vercel AI SDK v6.

02

GPT-4o selects tools

LLM reasons over 7 agent tools and decides which health services to call.

03

Token Vault check

Each tool fetches its token from Auth0 app_metadata at runtime. No token → graceful NOT_AUTHORIZED error.

04

Service call

Token validated, mock-data function called directly — no HTTP self-call. Result streamed back to patient.

05

Activity logged

Every token usage is recorded in the Activity Log — accessible via the top nav bar. Shows action, service, status, and timestamp.

// agent-tools.ts — getAvailableAppointments
execute: async ({ specialty }) => {
// 1. Fetch token from Auth0 Token Vault const token = await getServiceToken( userId, 'calendar' );
// 2. Guard — token absent if (!token) return notAuthorized( 'Appointments Calendar', 'calendar' );
// 3. Validate token, call directly — no HTTP if (!validateToken(token)) return notAuthorized(...); return getAvailableSlots(specialty);
};
// token-vault.ts — reads Auth0 app_metadata
export async function getServiceToken(
userId: string, serviceId: ServiceId
): Promise<string | null> {
const meta = await getUserMetadata(userId); const vault = meta.token_vault ?? {}; return vault[serviceId]?.token ?? null;
}
